## Automated Evidence

The Apple package compiles with complete Swift concurrency checks, exercises
the public facade and canonical workflow fixtures, runs external SwiftPM and
native C/Swift consumers, compiles generic iOS device and simulator targets,
and deterministically rebuilds the Rust XCFramework. Packaging emits a checked
archive, SPDX 2.3 SBOM, license, and validated native release manifest.
Streaming finalization tests validate the measured duration as elapsed metadata
rather than assuming that scheduler time is always zero.

## Physical Acceptance

for this candidate, including exact-serial selection, connection lifecycle,

not committed to this public repository.
