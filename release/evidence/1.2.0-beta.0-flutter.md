## Publication Controls

The synchronized release cannot complete from a partial candidate. It consumes
the successful exact-SHA CI inventory, establishes and checksums the immutable
Apple core asset, verifies or publishes the exact native CocoaPod through the
protected environment, and requires clean public SwiftPM, CocoaPods, Maven,
npm, Web, and Flutter resolution before completion.

For the first Flutter publication, the protected job prints the exact clean-tag
interactive command but does not execute it. Future exact version tags delegate
publication to Dart's reusable pub.dev OIDC workflow without a long-lived
repository token. The existing npm `latest` guard remains unchanged.
