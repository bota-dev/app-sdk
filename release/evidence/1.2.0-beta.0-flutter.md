## Publication Controls

The synchronized release cannot complete from a partial candidate. It consumes
the successful exact-SHA CI inventory, establishes and checksums the immutable
Apple core asset, verifies or publishes the exact native CocoaPod through the
protected environment, then requires clean public SwiftPM, CocoaPods, and Maven
resolution before rebuilding and comparing Flutter.

For the first Flutter publication, the protected job prints the exact clean-tag
interactive command but does not execute it. It then requires the public
pub.dev archive to download and verify before GitHub release completion. Future
exact version tags delegate publication to Dart's reusable pub.dev OIDC
workflow without a long-lived repository token. The legacy npm `latest` guard
remains unchanged.

## Public Evidence Unavailable

The `v1.2.0-beta.0` tag, immutable GitHub asset, synchronized Apple pod and
Maven artifacts, and pub.dev package do not yet exist. Public no-override
resolution and public-archive verification therefore remain unavailable by
design. No external publication or protected-environment action was authorized
or attempted while producing this evidence.
