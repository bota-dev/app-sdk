traces in its supported beta surface and explicitly classifies the four

available through the integrated native and React Native facades and is not

## Warnings And Limits

- Pigeon 28 generated Swift and the Flutter Apple adapter emit Swift 6
  sendability warnings. The plugin intentionally compiles that generated bridge
  in Swift 5 language mode. The separate native Apple SDK passes its strict
  Swift 6 warnings-as-errors gate.
- Flutter dependency resolution reports newer incompatible releases for
  `_fe_analyzer_shared`, `analyzer`, `material_color_utilities`, `pigeon`, and
  `test_api`; the pinned lock and generator remain the reviewed candidate.
- The Android consumer reported the known Kotlin Gradle plugin migration notice
  and an Android SDK XML version 3 versus 4 tool warning.
- The iOS consumer was intentionally unsigned and reported the future UIScene
  lifecycle migration warning. Material icon tree shaking was informational.
- No physical device, emulator, signed iOS archive, public package resolution,
  or public archive download was exercised in this local review.

## Publication Controls

The synchronized release cannot complete from a partial candidate. It consumes
the successful exact-SHA CI inventory, establishes and checksums the immutable
Apple core asset, verifies or publishes the exact native CocoaPod through the
protected environment, and requires clean public SwiftPM, CocoaPods, Maven,
npm, Web, and Flutter resolution before completion.

For the first Flutter publication, the protected job prints the exact clean-tag
interactive command but does not execute it. Future exact version tags delegate
publication to Dart's reusable pub.dev OIDC workflow without a long-lived
repository token. The existing npm `latest` guard remains unchanged.

## Public Evidence Unavailable

The `v1.2.0-beta.0` tag and synchronized public artifacts do not yet exist.
Public no-override resolution and public-archive verification therefore remain
unavailable by design. No external publication, workflow dispatch, protected
environment action, push, tag, or release was attempted while producing this
evidence.
