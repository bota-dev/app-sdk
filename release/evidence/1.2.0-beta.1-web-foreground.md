## Implemented foreground surface

- explicit picker connection, disconnect, exact serial verification, and fresh
  snapshot;
- exact previously authorized device reconnect when browser enumeration is
  available;
- recording list, legacy synchronization, encrypted-upload-v2 synchronization
  when freshly advertised, cancellation, recovery, and receipt-gated confirm;
- provisioning, remove-only deprovisioning, and connection settings;
- WiFi scan, configure, disconnect, status, and status subscription;
- host-authorized recording start and stop;
- integrity-checked firmware download, transfer, progress, cancellation,
  reload recovery, reboot, and exact-device reconnect;
- sanitized single-owner device-log subscription and explicit removal;
- tenant-scoped IndexedDB/OPFS persistence and BLE-free logout cleanup.

## Known exclusions

- background scan, service-worker Bluetooth, and closed-tab work;
- live recording streaming;
- authenticated destructive factory reset;
- Safari/iOS fallback transport or Bluetooth polyfill;
- Flutter Web and Windows;
- Bota API authentication or a generated backend API client.
