## Design review

The [per-requirement review](../../docs/parity/android-complete-resume-recovery.md)
compares the current encrypted-v2 resume and delete-after-confirmation contract
with the implementation. Android opens the manifest phase only after validated
full-length RESUME. Android and Apple reset only the accepted attempt's packet
counter, keeping durable identity, revision, prefix and progress checks intact.
Signed receipt and device CONFIRM remain the cleanup authority. Shared Rust,
backend API request schemas and firmware wire bytes are unchanged by this fix.

The first candidate's physical integrity failure remains recorded in the
[preflight snapshot](2.0.0-beta.12-preflight.md); the corrected physical test and
main verification above do not erase that history. Tagged packaged documents
retain their preparation checkpoint. This nonpackaged record supplies later
evidence without moving or replacing the immutable tag.
