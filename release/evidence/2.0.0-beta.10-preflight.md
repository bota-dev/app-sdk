## Acceptance limits

The prior public-beta.9 Flutter phone run reported intermittent GATT 8/133
reconnect failures; both failed clients closed promptly. This missing-disconnect
callback fix does not establish that issue's root cause or resolution. Preserve
the six Flutter example UI completion-ordering tests during adoption.
No beta.10 physical acceptance is established. Automatic reconnect, physical
iPhone/macOS/Web, background/out-of-range behavior, other phones/firmware and
recording/transfer interruption remain outside this bounded release evidence.
