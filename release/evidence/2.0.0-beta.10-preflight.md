direct pushes, with no PR. This release packages source `2ef85809`: when an
Android explicit disconnect times out or is cancelled without a native callback,
retire that exact generation, close its GATT client and notify native/facade
connection observers. Delayed loss consumes a one-shot retired generation without
cancelling queued replacement work; duplicates and stale generations are ignored.

## Acceptance limits

The prior public-beta.9 Flutter phone run reported intermittent GATT 8/133
reconnect failures; both failed clients closed promptly. This missing-disconnect
callback fix does not establish that issue's root cause or resolution. Preserve
the six Flutter example UI completion-ordering tests during adoption.
Public beta.10 RN passed 3/3 radio-off/explicit-reconnect cycles and graceful
disconnect on Samsung SM-A166U1 / Android 16 / Bota Pin firmware 1.0.19. Flutter
beta.10 phone acceptance is tracked separately in the examples review. Automatic reconnect, physical
iPhone/macOS/Web, background/out-of-range behavior, other phones/firmware and
recording/transfer interruption remain outside this bounded release evidence.
