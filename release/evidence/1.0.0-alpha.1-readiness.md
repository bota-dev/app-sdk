## Publication Gate

The initial crates.io release requires a one-time API token because Trusted
Publishing cannot be configured until the crate exists. No token is present in
the local environment, and the `v1.0.0-alpha.1` tag has intentionally not been
created. Stable `v1.0.0` remains reserved for the React Native-consumable
release.

Before publication, configure the protected GitHub `release` environment and
its `CRATES_IO_TOKEN` secret as documented in `docs/releasing.md`. After the
first release, migrate the workflow to crates.io Trusted Publishing and revoke
the bootstrap token.
