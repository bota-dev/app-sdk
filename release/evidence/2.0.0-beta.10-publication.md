## Later publication failures and current blocker

Attempt 5 progressed beyond Central publication. The npm CLI accepted the RN
package, but its bounded public-visibility check failed. Exact public RN bytes
were verified afterward; RN/Web registry bytes were also verified by the
subsequent successful publisher. Attempt 6 passed the publisher and native
consumer checks, then failed when CocoaPods reported a GitHub commit API timeout.
These failures were not additional Central polling timeouts.

Attempt 7 resumed only failed jobs under the original approval and completed
with the same CocoaPods failure. Its sole failed
[job 110441587593](https://github.com/bota-dev/app-sdk/actions/runs/36798449511/job/110441587593)
reported `[!] Calling the GitHub commit API timed out.` at
`2026-10-01T15:27:38.906Z`; the final failure exit was recorded at
`2026-10-01T15:32:46.917Z`. The successful publisher and native consumer results
remain valid; CocoaPods publication and its public-consumer gate are incomplete,
and the dependent Flutter publication has not run successfully.

The [CocoaPods Trunk controller](https://github.com/CocoaPods/trunk.cocoapods.org/blob/master/app/controllers/api/pods_controller.rb#L33-L35)
maps a GitHub commit timeout to HTTP 504. This supports identifying the failing
service interaction; it does not establish that an overall GitHub outage caused
this release failure. Exact beta.10 Trunk and pub.dev availability checks still
returned 404 after attempt 7; this checkpoint was recorded at 16:31 UTC on
October 1, 2026. Do not mark all five platforms published or execute
the full-success documentation update until the protected release and public
consumer checks complete.
