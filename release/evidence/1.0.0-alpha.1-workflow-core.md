# Workflow Core Evidence: 1.0.0-alpha.1

Date: 2026-08-30

## Scope

This evidence closes the deterministic workflow-core milestone for connection,
provisioning, authenticated factory reset, recording transfer, direct-upload
handoff, firmware update, and device-log streaming. It does not claim a native
transport, platform facade, application migration, physical-device acceptance,
or stable `1.0.0` readiness.

The following commands are the milestone gate:

```text
npm ci
npm run check
npm run test:tooling
npm run test:workflows -- \
  --sdk-path ../react-native-sdk

  --sdk-path ../react-native-sdk \
  --expected-commit 44ac1221cb71eb01cafcdbfdf7a370847d3a10b4

cargo clippy --workspace --all-targets -- -D warnings

cargo deny check
cargo package --locked --package bota-device-sdk-core
cargo publish --locked --package bota-device-sdk-core --dry-run
```

Local evidence used `--allow-dirty` for the two React Native comparison
commands because that sibling checkout contains only an unrelated pre-existing
`AGENTS.md` edit. The comparator still verified the exact baseline revision and
all referenced source/test anchors.
