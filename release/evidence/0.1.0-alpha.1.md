# Milestone 1 Evidence: 0.1.0-alpha.1

Date: 2026-08-28

## Scope

This evidence closes the pure protocol-core milestone. It covers repository
governance, synchronized version/release metadata, the frozen React Native
baseline, generated protocol constants, Rust models/errors, bounded parsers,
byte-exact serializers, and the typed workflow host boundary.

It does not claim Apple, Android, React Native replacement, Flutter, Web,
Windows, backend API client, FFI, or physical-device support. No public package
was published from this milestone.
