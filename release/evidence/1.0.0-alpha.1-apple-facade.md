# Apple Facade Acceptance Evidence: 1.0.0-alpha.1

Date: 2026-08-30
Status: Automated facade acceptance verified; physical-device acceptance not
run; Apple publication blocked.

## Scope

This evidence covers the source Apple facade, frozen ABI XCFramework, SwiftPM
consumer boundary, CoreBluetooth host, native persistence and material hosts,
public managers, generic iOS compilation, and deterministic unpublished release
metadata. The reviewed source identity is the commit containing this file; CI
records its exact SHA in the generated artifact manifest.

It does not claim a supervised Bota Pin or Bota Note run, authenticated reset
receipt, production-application migration, or a published Apple package. The
legacy native Apple baseline and React Native `0.0.65` behavioral baseline stay
authoritative until the physical matrix is complete.

## Publication Decision

`protocol/compatibility/firmware-compatibility.json` records the Apple facade as
`automated_verified`, its physical-device status as `not_run`, and publication
as blocked. Do not add Apple to `nativeAbi.publishedFacades`, replace the legacy
native baseline, create an Apple release tag, or publish the package until both
model rows and the separately gated authenticated-reset receipt are reviewed.
