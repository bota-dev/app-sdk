standalone snake_case type. This beta type-import migration is explicit in the
React Native README. Target lifecycle, confidentiality, and unsupported-platform
limitations are unchanged; metadata flags do not claim complete device qualification.

Main CI `36508099241` exposed a scheduler race in
`cancellationDuringAndAfterConfirmNeverSendsAbort`: the Default-dispatched
coroutine was not guaranteed to queue for the held mutex before CONFIRM was
released. It can validly find the session already removed and return false.
The test fix starts that coroutine UNDISPATCHED to establish the required order;
no production timeout, transfer behavior or assertion is weakened. The failed
main job is retried without rebuilding its successful platform artifacts. The
separate test-only revision must pass its own exact CI and License before merge.

The retry succeeded. The separate test-only fix `00a711e` also passed
[CI 36509128377](https://github.com/bota-dev/app-sdk/actions/runs/36509128377)
and [License Gate 36509130044](https://github.com/bota-dev/app-sdk/actions/runs/36509130044)
before merging to main. The beta.6 tag remains at `79dc984`; no release runtime
or occupied artifact was replaced by this test change.
