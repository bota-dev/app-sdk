# App SDK 2.0.0-beta.2 Preflight

Prepared on 2026-09-24 after the owner requested merge and publication through
normal CI. This record is not proof of registry publication or physical-device
acceptance. The annotated release tag must use the exact five-platform inventory
from successful main CI, not a locally built inventory.

## Scope

- Add Web `devices.connectSelected()` for a picker-driven connection and fresh
  serial discovery before application registration. Use the existing Rust
  `ConnectSelected` workflow and Device Information GATT serial read.
- Keep known-device connection and reconnect serial-strict, including rejection
  of malformed caller input before opening the picker.
- No firmware, BLE protocol, backend, provisioning, or Portal binding changes.
- Synchronize Apple, Android, React Native, Web, and Flutter at `2.0.0-beta.2`.
  Advance only npm `beta`; retain `latest -> 2.0.0-beta.0` and historical tags.

## Local Verification

- Web: 382 tests, type checks, 28 tooling tests, and production Vite packaging
  passed. All eight Chromium consumer cases passed with the final packed README,
  including serial discovery without manual SN input and picker gesture checks.
- React Native: package verification, Codegen, type checks, 80 compatibility
  tests, build, and dependency licenses passed; the exact npm tarball was packed.
- Repository tooling: 104 tests passed; release tooling: 92 tests passed.
- Apple: fresh generated archive checksums reproduced in clean check mode.
  The strict-concurrency suite reported 200 tests, nine physical tests skipped,
  and no failures.
- Android: two clean builds matched byte-for-byte; all four ABI inspections,
  unsigned Maven packaging, publication metadata, and dependency licenses passed.
- Root dependency licenses, generated protocol constants, Rust formatting, and
  Clippy with warnings denied passed.

- Flutter: analysis, Pigeon/format checks, Dart tests, dependency licenses,
  and pub dry run passed, followed by fresh Android and iOS release-app builds.
  Both consumers used native beta.2, and the temporary consumer was removed.
- All five example artifact SHA-256 values match their actual local archives.
  The Flutter archive inventory, synchronized manifest, and verify-tag checks
  passed. These hashes are not a substitute for the main-CI release inventory.

- The final Rust workspace rerun passed with no failures.
