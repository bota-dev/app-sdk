## Source and acceptance boundaries

Published source passes 526 RN tests, 146 native/generated-JS comparisons and
777 pinned Hermes checks. Its canonical 3,971,776-byte core has SHA-256
`46760f5cdc98a7622a802728ba4eab216c7ced0846023b71d1153ed03f160393`.
Shared behavior remains Rust-sourced over the unchanged version 1 OS ports.
The release includes transfer batching, joined lifecycle/control cleanup,
bound-model settings hints, exact managed-v2 create identity and the existing
`backgroundSyncEnabled: false` automatic-admission correction. Explicit app sync
remains an independent trigger; signed receipts still gate device cleanup.
