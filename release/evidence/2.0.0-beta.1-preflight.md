# App SDK 2.0.0-beta.1 Preflight

Prepared on 2026-09-24. The release owner authorized normal CI and protected
publication. This is local preflight evidence, not publication or hardware
acceptance. The release tag must bind the five-platform inventory produced by
green main CI, not these local archive hashes.

## Scope

- Include Flutter Android SDK discovery fix `b797aa2`: normal consumers use
  `local.properties` without `BOTA_FLUTTER_HOME` or `FLUTTER_ROOT` overrides.
- Synchronize Apple, Android, React Native, Web, and Flutter at `2.0.0-beta.1`.
- Include the post-beta.0 evidence-attachment and protected Flutter OIDC fixes.
- Advance only new npm `beta` tags. Keep new-name `latest` at `2.0.0-beta.0`
  and all legacy versions and tags unchanged.
