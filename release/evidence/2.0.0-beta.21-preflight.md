## Protocol review and limits

`FIRMWARE_PROTOCOL.md` and `protocol/device-token-v1.md` are the contract.
Registration requests `credential_delivery: "hpke_v1"`; the app relays only
`credential_envelope` to `provisionEnvelope` and confirms only after successful
device provisioning. Plaintext fallback is forbidden. Firmware must implement
the dedicated B07A000A-0001 credential characteristic and have independent
trusted serial-to-PK_D enrollment with matching environment and signing trust.
Reading a public key does not prove protocol support.

Firmware PR #56 source and compilation are not a qualified flashable release.
No backend deployment, database changes, credential creation, device binding,
unbinding, reset, reconnect, or flashing is part of this release preparation.
Pin3EV953HUIA remains frozen. Bota One and Notion edits are outside scope.
Source, built artifacts, uploaded distribution and installed-device evidence
must be reported separately. The design-review skill is unavailable; this
requirement/evidence checklist records the review directly.
