# 2.0.0-beta.11 managed encrypted-v2 backend adapter

The owner authorized test, commit, direct main integration without a PR, and
publication. React Native iOS/Android gains `createEncryptedUploadV2Backend`:
customer-proxy HTTPS, fresh scoped credentials, native session journaling,
manifest replay before PUT, bounded verification polling and receipt delivery.
Existing custom providers remain valid; native material APIs gain an optional
reconciliation callback. All five package versions remain synchronized.

See [per-requirement review and customer wiring](../../docs/parity/v2-managed-backend.md).
The backend recovery fix is already deployed; this release changes the SDK.
It does not change firmware rollout flags, legacy API semantics, standalone
native/Flutter/Web integration, initial unknown-create reconciliation or
OS background execution. Hardware interruption acceptance is not established.

Exact tag and npm/Maven/CocoaPods/pub.dev slots were checked unoccupied before
preparation. Beta.10 and historical versions remain immutable; preserve npm
`latest` at beta.0. Generated package checksums are provisional until replaced
from the exact CI candidate. No source preparation claims publication.

Local checks: eight new JS tests, TypeScript/build and Codegen pass. Full
Linux/macOS CI and License Gate are required on the exact candidate. Windows
cannot run the POSIX journal fsync suite; unrelated existing Windows URL-path
and CRLF vector fixtures are covered by canonical hosted CI. Publication and
public consumers remain pending.
