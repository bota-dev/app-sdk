## Remaining release gates

`runtimeWorkflow` and `firmwareAdvertised` remain `false`. A future release may
change those claims only after the matching firmware advertises the capability,
the synchronized SDK artifacts are published, and the supervised physical
hardware matrix passes. Until then, applications must not infer v2 support from
firmware versions, device models, stored keys, or this source evidence.
